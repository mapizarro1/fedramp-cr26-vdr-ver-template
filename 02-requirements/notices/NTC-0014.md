# NTC-0014: FedRAMP Response to CISA BOD 26-04

Published: 2026-06-16

## What it is
FedRAMP's response to CISA Binding Operational Directive 26-04 (released
2026-06-10), which reprioritizes vulnerability remediation around public exposure,
KEV status, exploit automatability, and technical impact. NTC-0014 accelerates
mandatory adoption of the VDR and VER rulesets.

## Effect on a Rev5 Class C CSO
- VDR + VER become mandatory 2026-12-07 (earlier than the general 2027-01-01 CR26
  Rev5 date), grace period to 2027-03-07, certification revoked after that if not
  following the rules.
- Following VER/VDR satisfies BOD 26-04 by default. Not a separate compliance track.
- The legacy monthly-scan-by-CVSS model is explicitly called insufficient.

## Where the work lives
Workstream 01 (04-workstreams/01-vdr-ver/). Full Class C analysis and the
pipeline/template changes are in that workstream's gap-analysis.md.

## Caveat
NTC-0014 flagged that rule wording could shift slightly during the final preview
window. The change watcher (05-automation/bin) covers that; re-confirm against
the live ruleset before freezing any number into a procedure.
